# After-hours support

## Check the agreement
The Service Desk is staffed from 08:00 to 16:00 on weekdays in Europe/Helsinki. The current customer agreement determines which requests qualify for duty technician handling.

## Escalate eligible cases
Use the internal duty queue. Include the customer ID, device ID if applicable, current impact, callback details and checks already completed. Record who accepted the handover. If the contract directs the case to the next business day, leave a handover note.
